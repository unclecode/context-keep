# Kenney UI Audio

The keystroke, Enter and Esc sounds come from Kenney UI Audio.

Source: https://kenney.nl/assets/ui-audio
Mirror used: https://github.com/Calinou/kenney-ui-audio
Licence: CC0 1.0. Public domain. No attribution required, commercial use allowed.

click4 -> key1, click5 -> key2, click2 -> key3, click1 -> enter, click3 -> esc.
Each is converted to mono 48 kHz and normalised to -18 LUFS.
The other seven sounds are built by make_sounds.py.
